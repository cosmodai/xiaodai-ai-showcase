03 / 多 agent 编排

一次任务的执行轨迹

用合成记录回放小戴处理一个定时任务的全过程：主脑派单、hook 拦截、子 agent 声称完成、完成断言回读，直到收到回执。逐步点击，看每一步留下的证据。

任务

每周一早上自动生成「北区周报」，数据截至上周日，发到运营群。

    点击“下一步”开始。

    第 2 步：路由写成一句话是无效的，hook 也看不到。只有调用调度工具、带上枚举参数，派单才算发生。

    第 4 步：外发动作只能经过发件箱，子 agent 直接发消息会在调用前被拦下。

    第 6 步：子 agent 说“完成”，但回读发现数据日期是上上周。断言让这次“完成”变成退回。
